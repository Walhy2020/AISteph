# v0.7.0 AISteph Voice Windows 客户端

AISteph 的录音模块正式命名为 **AISteph Voice**。本版本把网页工作台、录音服务、托盘快捷键和版本检查整合为一个 Windows 客户端入口。

## 客户端体验

- 双击 `AIStephVoice.exe` 自动启动内部录音服务并打开内嵌工作台，不再依赖外部浏览器。
- 使用系统级单实例锁；重复启动不会产生第二套服务，而是唤醒已有窗口。
- 关闭或最小化主窗口后继续在系统托盘运行。
- `Ctrl + Alt + R` 在任意 Windows 界面开始或停止录音。
- 退出前检查录音状态；正在录音时必须确认停止并保存。
- 托盘菜单提供打开窗口、录音切换、检查在线更新和退出。
- 版本号移动到左上角品牌旁，顶部不再显示服务状态。
- 右上角统一“设置”面板集中展示增益增强、全局快捷键、跟随系统启动、录音文件位置和在线更新。
- 跟随系统启动使用当前用户启动项，并以后台托盘模式运行。
- 录音目录显示真实本地路径，可直接从设置中打开。

## 品牌

- 名称统一为 `AISteph Voice`。
- 图标采用绿色 `#2E9B64` 方形底和白色 `S`。
- `S` 垂直居中并水平靠右，用于 EXE、托盘、启动页和网页导航。

## 服务与数据

- 客户端优先使用随包携带的 Node、FFmpeg 和 FFprobe，并在后台启动服务。
- 安装版个人数据保存在 `%LOCALAPPDATA%\AISteph Voice`，程序更新不会覆盖录音和配置。
- 开发环境仍可通过 `npm run web` 单独运行管理台。

## 在线更新

- 启动后静默查询 GitHub Releases 最新稳定版本。
- 客户端运行期间每 12 小时复查一次。
- 用户也可通过托盘菜单手动检查。
- 发现更新后显示版本并打开 GitHub 安全下载页面；当前阶段不在录音过程中自动替换程序文件。

## 构建

```powershell
npm run build:voice
npm run publish:voice
```

自包含发布目录为 `dist/AIStephVoice`，日常入口为 `AIStephVoice.exe`。
