# v0.4.4 录音设备防误选

## 问题

页面首次加载时直接使用 DirectShow 返回的第一个设备。蓝牙耳机尚未完成枚举时，网易虚拟音频设备可能被自动选中，造成录音无声。

## 变更

- 记住上次选择的实体麦克风，后续优先恢复。
- 首次使用时优先选择耳机、Headset 和 Hands-Free 设备。
- 网易虚拟音频设备显示为“不可用于录音”并禁止选择。
- 其他虚拟音频设备不会自动选择，也不会保存为默认麦克风。
- 上次使用的耳机暂未出现时保持未选择状态，不回退到其他设备。
- 设备缺失时按 1、2、4、8 秒自动重试；仍未出现后提示连接设备并手动刷新。

## 兼容性

- 设备选择只保存在本机浏览器中。
- 不改变录音文件、增益、声纹、资料库和播放接口。
- 用户手动选择的其他实体麦克风在刷新时保持不变。
