# v0.5.0 Apple 风格工作台

依据项目根目录 `DESIGN.md` 的设计系统重新构建录音工作台视觉层，同时保留全部录音、声纹、设备、播放和删除能力。

## 页面结构

- 44px 黑色全局导航与 52px 毛玻璃产品副导航。
- 桌面端使用白色录音区与近黑色资料库区组成的全宽双栏布局。
- 833px 以下改为上下堆叠，640px 以下录音卡片使用单列。
- 资料库仍保持独立滚动与紧凑双列卡片，避免减少可见录音数量。

## 设计约束

- 所有主要交互统一使用 Action Blue `#0066cc`。
- 使用 SF Pro 系统字体回退与紧凑字距。
- 主要操作、输入框和筛选操作统一使用胶囊形态。
- 页面不使用装饰性渐变，也不对卡片、按钮和文字添加阴影。
- 明暗区块的颜色变化承担页面分区，不增加装饰边框或浮层。
