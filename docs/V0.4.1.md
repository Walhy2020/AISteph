# v0.4.1 紧凑录音工作台

## 本阶段目标

减少非必要展示，让开始录音、停止保存和历史播放集中在一个更高密度的工作区中。

## 变更

- 删除页面顶部宣传文案和统计区，录音工作区直接进入首屏。
- 开始录音和停止保存合并为同一个状态按钮。
- 未填写标题时，以点击开始录音的本地时间作为标题。
- 录音资料卡移除 SRC ID、原始文件路径、设备和等待分析标签。
- 资料卡仅保留标题、录制时间、时长和播放器。
- 资料列表随浏览器高度扩展，并压缩卡片间距和内部留白。
- 保留签名播放地址、Range 播放、单音频互斥和播放期间暂停自动刷新。

## 兼容性

- 录音、停止、音频校验和数据入库接口未改变。
- 原文字、文章和文件接口仍保留但不在页面显示。
- 已存在录音记录无需迁移。

## 边界处理

- 启动或停止请求期间按钮禁用，避免重复操作。
- 录音中按钮切换为红色停止状态。
- 服务恢复后，按钮状态以服务端录音状态为准。
- 空标题兜底在服务端生成，避免刷新页面或客户端差异导致标题丢失。
