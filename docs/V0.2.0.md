# v0.2.0 PC统一收件箱管理台

## 本阶段范围

本阶段在v0.1.0统一数据结构上增加可日常使用的PC本地管理页面。

已包含：

- 本地状态、版本和收件箱统计。
- 文字、文章链接和文件收录表单。
- 待审核资料列表和类型筛选。
- 文件流式上传和大小限制。
- API进程令牌、同源校验和浏览器安全响应头。
- 本地服务与接口结构化日志。
- 响应式PC页面，小屏幕仍可使用。

暂不包含：

- Obsidian内的确认、归档和正式知识发布操作。
- 网页正文抓取和文档内容解析。
- AI摘要、分类和知识提炼。
- 麦克风录音、VAD和语音转写。
- Windows托盘程序和开机自启。

## 启动

```powershell
npm run web
```

默认只监听：

```text
http://127.0.0.1:39310
```

端口可在 `./config/aisteph.json` 中使用 `serverPort` 调整。服务不接受非本机地址绑定。

## 安全和隐私

- 页面中的进程令牌每次启动重新生成，不写入磁盘和日志。
- 所有API均要求令牌；写接口额外验证同源。
- 页面设置CSP、禁止iframe嵌入并关闭缓存。
- 文件上传默认限制100MB，可通过 `maxUploadBytes` 调整。
- 文件名只保留basename，不能通过 `../` 写出资料目录。
- HTTP日志只记录方法、路由、状态、耗时和错误类型，不记录正文或文件内容。
- `./data`、`./vault`、`./logs` 和本地配置继续被Git忽略。

## 验收标准

1. 页面、页脚和状态区域显示 `v0.2.0`。
2. 服务只绑定 `127.0.0.1`。
3. 无令牌API访问返回403。
4. 带令牌的跨来源写入返回403。
5. 文字、链接和文件都能进入同一待审核列表。
6. 文件名不能逃逸本地资料目录。
7. 超限文件返回413且不生成收件箱记录。
8. 所有v0.1.0测试继续通过。
9. 浏览器无控制台错误，PC布局和交互可用。
