# v0.6.0 Windows 全局快捷录音

这一版本解决“必须先打开网页才能录音”的问题：AISteph 服务启动后会自动运行轻量 Windows 托盘助手，通过系统级快捷键直接控制现有录音后台。

## 使用方式

- `Ctrl + Alt + R`：开始录音；再次按下停止并保存。
- 双击托盘图标：开始或停止录音。
- 右键托盘图标：开始/停止录音、打开录音工作台或退出快捷键助手。
- 每次操作都会通过 Windows 系统通知反馈成功或失败。

## 设备安全

- 网页选择的实体麦克风与录音增益会持久化给快捷键助手。
- 若默认耳机已经断开，快捷键会提示设备不可用并取消录音。
- 不会自动回退到网易虚拟音频、其他虚拟设备或未经确认的麦克风。
- 第一次使用前仍需打开一次网页确认设备；之后日常录音无需保持网页打开。

## 技术实现

- 新增受本地令牌和同源校验保护的 `/api/recorder/toggle` 接口。
- 新增录音偏好持久化文件 `./data/recorder-preferences.json`，继续由 Git 忽略。
- 新增 `AIStephHotkey.exe` 托盘助手，使用 Windows `RegisterHotKey` 注册全局快捷键。
- 正式运行 `node src/server.js` 时自动启动助手；测试服务器不会启动桌面进程。
- 托盘程序源码位于 `tools/hotkey`，可通过 `npm run build:hotkey` 重建。
