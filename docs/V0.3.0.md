# v0.3.0 PC手动事件录音

## 本阶段目标

在现有 PC 统一收件箱中增加可控、可见、可立即停止的手动录音能力。录音负责可靠采集，AI 转写和分析继续保持解耦。

## 已实现

- 使用 FFmpeg DirectShow 枚举 Windows 音频输入设备。
- 选择麦克风后开始单场录音，同一时间只允许一场。
- 管理台显示录音状态、所选设备和持续时长。
- 停止时优先向 FFmpeg 标准输入发送 q，等待 Opus 容器正确封装。
- 停止超时后终止子进程，并清理临时文件。
- 使用 ffprobe 校验 Opus 编码和有效时长。
- 音频保存在 ./data/audio/YYYY-MM-DD/REC-*.opus。
- 成功校验后生成 audio 统一记录、处理队列和 Obsidian 待审核笔记。
- 服务退出时主动结束正在进行的录音。
- 日志记录会话ID、设备、时长、文件大小、退出码和错误，不记录音频内容。

## API

- GET /api/recorder/devices
- GET /api/recorder/status
- POST /api/recorder/start
- POST /api/recorder/stop

所有 API 继续受本地进程令牌保护；写接口继续执行同源校验。

## 暂不包含

- AI 转写和摘要。
- VAD 自动分段。
- 全天连续录音。
- 移动端、托盘和开机启动。
- 自动上传云端。

## 验收重点

- 麦克风缺失、设备拔出或 FFmpeg 启动失败不会产生正式收件箱记录。
- 只有成功停止并通过 ffprobe 校验的音频才会进入 Obsidian 待审核区。
- 录音文件、记录、笔记及配置内的数据路径均使用项目相对路径。
