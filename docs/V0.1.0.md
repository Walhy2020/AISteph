# v0.1.0 第一阶段设计与验收

## 本阶段范围

本阶段建立统一收件箱内核，验证不同资料可以使用同一数据模型进入 Obsidian 待审核区。

已包含：

- 工作区初始化。
- 文字收录。
- 文章链接收录。
- 本地文件导入。
- 原始资料、记录、队列、Obsidian 笔记和结构化日志。
- 命令行版本显示。

暂不包含：

- 麦克风录音与 VAD。
- AI 自动分析和云端上传。
- 网页正文抓取。
- Windows 托盘界面。
- 移动端与企业微信。

## 验收标准

1. `init` 重复运行不会破坏已有数据。
2. 三类信息均能生成状态为 `pending_review` 的统一记录。
3. 导入文件后，原文件保持不变，副本位于 `./data`。
4. Obsidian Inbox 笔记带有来源、哈希、可见性和审核清单。
5. 日志仅记录 ID、事件、类型、耗时和错误，不记录正文。
6. 配置中的存储路径只能是项目内的相对路径。
7. 程序输出版本号 `v0.1.0`。

## 已知边界

- 链接当前只保存 URL，不请求或解析网页正文。
- 文件导入不解析 PDF、Word 或图片内容。
- 尚未提供同内容合并策略，避免未经用户确认自动丢弃来源。
- 命令行参数中的文字可能出现在本机 shell 历史中，正式桌面端将改为输入框或剪贴板导入。
